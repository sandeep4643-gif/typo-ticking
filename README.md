# 💣 TYPO TICKING – Typing-Based Bomb Defusal Game

TYPO TICKING is an interactive browser-based typing game built using **HTML, CSS, and JavaScript**. Players must type sentences accurately before the countdown timer reaches zero to successfully defuse a virtual bomb.

The game combines typing challenges, time pressure, sound effects, and visual animations to create an engaging gaming experience.

## Features

- **Three Difficulty Levels:** Easy, Medium, and Hard.
- **Progressive Challenges:** 3 stages with 5 sentences each (15 challenges in total).
- **Countdown Timer:** Race against time to complete each challenge.
- **Bonus Time:** Earn additional time by completing stages.
- **Live Statistics:** Track Words Per Minute (WPM), typing accuracy, and completed sentences.
- **Sound Effects:** Countdown ticks, warning alerts, stage completion sounds, and explosion effects.
- **Visual Effects:** Bomb shaking, warning animations, stage transitions, and defusal celebrations.
- **Responsive Design:** Play on desktop and mobile devices.
- **Sound Controls:** Toggle game audio whenever you want.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Web Audio API

## How to Play

1. Open the game.
2. Select your preferred difficulty level.
3. Read the mission instructions.
4. Type each displayed sentence exactly as shown.
5. Complete all 3 stages before the timer expires.
6. Successfully complete all 15 challenges to defuse the bomb!


## Project Goal

This project was built to explore JavaScript programming, DOM manipulation, event handling, timers, audio generation, CSS animations, and responsive web design through a fun, interactive application.

**Type fast. Stay accurate. Defuse the bomb!** 💥
